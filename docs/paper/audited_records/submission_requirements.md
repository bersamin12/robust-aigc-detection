# SAFE submission requirements checked November 2, 2026

The [official SAFE @ AAAI 2027 call](https://www.safeworkshop.org/aaai-2027/) specifies full papers of **6–8 pages excluding references**, formatted with the AAAI-27 author kit, and a deadline of **November 4, 2026 at 11:59 pm ET**. That is November 5 at 12:59 pm Singapore (ET is UTC−5 at this date).

The [public OpenReview group](https://openreview.net/group?id=AAAI.org/2027/Workshop/SAFE) links to the submission process. The [public invitation API](https://api2.openreview.net/invitations?id=AAAI.org/2027/Workshop/SAFE/-/Submission) returned the fields `title`, `authors`, `keywords`, `TLDR`, `abstract`, `pdf`, `email_sharing`, `data_release`, `venue`, and `venueid`. Only `pdf` has `type=file`, with PDF extension and maxSize=50. The exact retrieved public schema is saved in `submission_form_schema.json`.

The current form does not expose a separate supplemental file upload. Keep the supplement and source ZIP separate; the venue's supplemental attachment route remains to be confirmed. This audit did not contact organizers, publish, submit, or attach anything. Do not interpret a local package as uploaded supplementary material.

The older repository README records an earlier deadline. It is preserved as an existing artifact; the current package instructions supersede it for this submission.
